# Projects

The public face of a personal multi-project AI system built by
KetchupPancake W (KetchupPancake) in Calgary, Alberta — a multi-model swarm,
a local home lab, a research pipeline, and the projects they serve.

## Pages

- **`dashboard.html`** — the project architecture dashboard: the ten
  projects, how they connect, each project's mission, and the state
  of observability within each project.
- **`funding.html`** — the public funding page: what is being built
  and the programs it fits.

## Mission statements

Filed 2026-11-08 after a node-by-node review of the whole system.

- [Hydra](missions/Hydra-MISSION.md) — the multi-model system:
  data as a service, intelligence and free compute, evaluations as
  the hinge.
- [Academy](missions/Academy-MISSION.md) — the source of truth:
  a connected index of human knowledge, and a school.
- [Studio](missions/Studio-MISSION.md) — the creative hub: pipelines
  and art-school knowledge for real films and promos.
- [The Still](missions/TheStill-MISSION.md) — the research pipeline:
  where outside claims earn the right to influence the system.
- [Night Shift](missions/NightShift-MISSION.md) — the overnight
  engine: free compute spent only where it justifies itself.
- [Cora](missions/Cora-MISSION.md) — the local layer: the home lab
  everything stands on.
- [The Office](missions/TheOffice-MISSION.md) — business
  implementation for small-to-medium enterprises; flagship project
  Foreman.
- [The Workbench Laboratory](missions/WorkbenchLaboratory-MISSION.md)
  — the empirical node: where claims are tied to what actually
  happened.
- [Shared Workspace](missions/SharedWorkspace-MISSION.md) — the
  common ground: the cloud's open layer and the home lab, one record.
